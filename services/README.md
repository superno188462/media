# 服务与工具接入目录

每个服务独占一个子目录。服务目录是该服务的项目根目录，包含源码、依赖声明、启动入口、配置模板和部署文件；运行环境由服务自己管理，各服务可独立运行和构建 Docker 镜像。`.local/` 只保存本机私有凭据、持久化数据和临时记录，不保存服务源码或依赖环境。

| 模块 | 当前状态 | 入口 |
| --- | --- | --- |
| [bilibili](bilibili/README.md) | 上游 `bili-cli` 源码固定在服务目录；服务专属运行环境；账号读取已实测。当前以独立 CLI 进程调用，尚无 Streamable HTTP 服务 | `bilibili/bili.cmd` 或根目录 `bili.cmd` |

未来新增抖音、飞书、记忆等服务时分别新建目录，包含各自源码、依赖锁定、启动入口、配置示例和 Dockerfile。DSH 通过明确的插件/MCP 边界调用服务；不把一个服务的执行环境放进另一个服务或共享 `.local/`。
