# 宠物素材目录

角色动画的**唯一素材来源**。生成一次、所有视频复用。

## 目录约定

```
assets/pet/
├── idle/         待机（呼吸、轻微晃动）      6–8 帧
├── eat/          吃东西                      6–8 帧
├── sleep/        睡觉                        6–8 帧
├── wave/         挥手                        4–6 帧
├── grab/         被抓起来（脚悬空、手垂下）   2–4 帧
├── hand.png      从上方伸下来的手（单张）
└── README.md     本文件
```

`idle/` 是**必需的**（缺了配置校验会直接报错），其余按需增删。

## 帧文件要求

| 项 | 要求 | 原因 |
| --- | --- | --- |
| 格式 | PNG，RGBA | 需要透明通道叠加到背景上 |
| 文件名 | `00.png`、`01.png`… 两位补零 | 播放按文件名排序，不是按时间 |
| **画布** | 同一动作内**完全一致** | 尺寸不一致混合时会报错 |
| 背景 | 必须**全透明** | 抠图后用 `trim_transparent` 裁掉多余边 |
| 对齐 | **脚底对齐、水平居中** | 否则循环播放时角色会上下跳 |
| 帧数 | 4–8 帧 | 太多会在生图阶段出现明显漂移 |

## 新增一个动作

1. 用豆包 Seedream 按同一角色描述生成 6–8 张，只改姿态描述
2. 抠图：`content.imagegen.cutout.remove_background`
3. 归一化：统一缩放到 900 高 → 居中到同宽画布 → 脚底对齐
4. 放进 `assets/pet/<动作名>/`
5. 在 `examples/pet_config.json` 的 `clips` 里加一行

**提示词要点**：角色描述必须逐字复制，只改最后一句姿态。
否则每一帧的脸和衣服都会漂，循环时看起来像在闪。

## 已知限制

- 帧与帧之间仍有轻微漂移（生图无法保证完全一致），靠 `crossfade` 掩盖
- 没有真正的骨骼动画；动作幅度受限于"同一张图换姿态"
- 参考视频那种 Live2D 级连贯性需要绑定工具，不在当前范围内
